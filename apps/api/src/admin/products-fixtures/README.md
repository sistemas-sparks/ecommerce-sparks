# Fotos sintéticas de teste

Retângulos coloridos gerados em canvas e convertidos pelo painel da T-008 em WebP,
com 360×450, 720×900 e 1080×1350 pixels. Não são fotos da cliente e não entram na vitrine.

As fixtures preservam o perfil de cor que o encoder acrescentou. Os testes conferem
que a remoção de metadados produz um arquivo aceito pela API e que o original é recusado.
A especificação usada está em
[WebP Container Specification](https://developers.google.com/speed/webp/docs/riff_container).
