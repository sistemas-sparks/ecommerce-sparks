# Fontes

- **Big Shoulders Text** (fonte da marca): títulos. Pesos 500, 600, 700 e 800.
- **Nunito**: textos. Pesos 400, 600, 700 e 800.
Subconjunto latino (cobre acentos do português), formato WOFF2, licença SIL Open Font License (ver arquivos LICENSE).
A cliente recebeu do designer o pacote `4 Sparks - Fonte.zip` com a família completa em TTF; se for preciso outro peso, pedir esse arquivo.
O texto do logotipo tem ajustes próprios: **nunca** substituí-lo por texto digitado com a fonte.
