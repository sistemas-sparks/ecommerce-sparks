# Logotipo

- `logo-alternativo.png`: clipe vertical + "Papelaria Sparks" (uso no cabeçalho).
- `logo-original.png`: clipe horizontal sobre o texto (rodapé, documentos).
- `simbolo.png`: os dois clipes (seções de marca, ícones).
Fundo transparente, cores RGB da marca: rosa `#F7B7C4`, orquídea `#DEA6CA`, malva `#948588`.

`originais/` traz as páginas das variações exportadas pelo designer (RGB para telas, CMYK para impressão), incluindo as versões monocromáticas.
Os PNG foram extraídos dessas páginas. Para impressão ou ampliação, peça os vetores originais (arquivo CDR/PDF vetorial) à cliente.
**Nunca** redesenhar o logo nem recriar o texto com a fonte.
