# Kit de SEO

Arquivos-base para a T-022. Substitua `{{SITE_URL}}` pelo domínio final (ex.: `https://www.sparkspapelaria.com.br`) e os campos `[A DEFINIR]` quando a cliente confirmar.
O sitemap real deve ser **gerado no build** a partir dos produtos ativos; `sitemap.example.xml` mostra o formato.
Estratégia e checklist: `docs/seo.md`.
